### Базовые инструменты защиты и автоматизированного контроля
#### Application Level
- Spring Security Crypto
#### Database Level
- Postgres TDE plugin + Row-Level-Security
#### SIEM / Log‑Management
- ELK SIEM или Splunk для сбора логов доступа и событий шифрования
- Grafana Alerting для отправки нотификаций
#### DLP (Data Loss Prevention)
- InfoWatch DLP для мониторинга и предотвращения утечек в условиях размытого периметра (e-mail, USB)
#### Хранение и ротация ключей
- HashiCorp Vault для хранения ключей
- Политики Vault для настройки ротации
